# Документація Структури Проекту ВІА ПРО v2

Цей документ містить детальну інформацію про структуру проекту, призначення основних директорій та файлів, а також інструкції щодо роботи з кодовою базою.

## 🛠 Технічний Стек
- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS + clsx/tailwind-merge
- **Animations**: Framer Motion
- **Routing**: React Router DOM (v7)
- **Maps/Geo**: D3 Geo, TopoJSON

## 📂 Структура Директорій

### Коренева Директорія (`/`)
Тут знаходяться конфігураційні файли проекту.

- **`package.json`**: Головний файл проекту. Містить перелік залежностей (dependencies), скрипти для запуску (`dev`, `build`, `lint`) та метадані проекту.
- **`tsconfig.json`** (**& `tsconfig.app.json`, `tsconfig.node.json`**): Налаштування TypeScript для компіляції коду.
- **`vite.config.ts`**: Конфігурація збирача Vite. Тут налаштовуються плагіни (наприклад, для React), аліаси шляхів тощо.
- **`tailwind.config.js`**: Налаштування Tailwind CSS (кольори, шрифти, розширення теми).
- **`postcss.config.js`**: Конфігурація PostCSS (використовується Tailwind).
- **`.gitignore`**: Список файлів та папок, які ігноруються системою контролю версій Git (наприклад, `node_modules`).

### Публічні Ресурси (`/public`)
Файли в цій папці доступні публічно без обробки збирачем.
- **`/locales`**: Ймовірно, містить файли перекладів (якщо планується багатомовність).
- **`vite.svg`**: Логотип Vite.

### Вихідний Код (`/src`)
Основна папка з кодом додатку.

#### `src/pages`
Містить основні сторінки додатку, які відповідають маршрутам (routes).
- **`Home.tsx`**: Головна сторінка.
- **`Projects.tsx`**: Сторінка проектів ("Портфоліо").
- **`Career.tsx`**: Сторінка вакансій ("Кар'єра").

#### `src/components`
Перевикористовувані компоненти UI.
- **`/ui`**: Базові UI елементи (кнопки, інпути, картки тощо).
- **`/layout`**: Компоненти макету (Header, Footer, Navigation).
- **`/services`**: Компоненти для відображення послуг.

#### `src/data`
Статичні дані, винесені в окремі файли для зручного редагування контенту без зміни коду компонентів.
- **`projects.ts`**: Містить масив об'єктів з інформацією про проекти (назви, описи, зображення).
- **`companyInfo.ts`**: Загальна інформація про компанію.
- **`mapPaths.ts`**: Дані для відмальовки карти або шляхів (геодані).

#### `src/layout` (або `src/components/layout`)
Зазвичай тут знаходяться обгортки сторінок.
*(Примітка: У вашій структурі папка `layout` є як в `components`, так і, можливо, окремо, перевірте точне розташування).*

#### `src/assets`
Зображення, іконки та стилі, які імпортуються безпосередньо в компоненти.

#### `src/lib`
Утиліти та допоміжні функції.
- **`utils.ts`**: Зазвичай містить функцію `cn` (classnames) для зручного об'єднання класів Tailwind.

#### Основні файли в `src/`
- **`App.tsx`**: Головний компонент додатку, де налаштовується маршрутизація (Routing).
- **`main.tsx`**: Точка входу в додаток. Тут React-додаток монтується в DOM (`root` елемент).
- **`index.css`**: Глобальні стилі та підключення Tailwind директив.
- **`App.css`**: Стилі конкретно для App компонента (якщо використовуються).

## 🚀 Як користуватися (Скрипти)

Основні команди для терміналу (запускати з кореня проекту):

1.  **Запуск локального сервера розробки**:
    ```bash
    npm run dev
    ```
    Відкриває додаток за адресою `http://localhost:5173`. Зміни в коді відображаються миттєво (HMR).

2.  **Збірка проекту для продакшну**:
    ```bash
    npm run build
    ```
    Створює оптимізовані файли в папці `dist`.

3.  **Попередній перегляд збірки**:
    ```bash
    npm run preview
    ```
    Дозволяє перевірити зібраний проект (з папки `dist`) локально.

## 📝 Як редагувати контент

1.  **Додати новий проект**:
    - Відкрийте `src/data/projects.ts`.
    - Додайте новий об'єкт у масив за аналогією з існуючими.

2.  **Змінити текст вакансій**:
    - Перевірте файл `src/pages/Career.tsx` або, якщо дані винесені, `src/data`.

3.  **Змінити навігацію**:
    - Меню зазвичай знаходиться в `src/components/layout` (наприклад, `Header` або `Navbar`).

## 💡 Поради щодо розробки

- Використовуйте **компоненти** з `src/components/ui` для збереження єдиного стилю.
- Для стилізації використовуйте класи **Tailwind CSS**.
- Якщо потрібно додати складну логіку, створіть хук в папці `src/hooks` (якщо така є) або прямо в компоненті.
